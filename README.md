命令执行器 (Command Runner)



这是一个基于 C++ 和 Qt6 开发的图形化命令行执行工具。



功能特性

\- 实时显示命令输出（支持标准输出与错误输出）

\- 支持中断/强行终止正在运行的命令

\- 内置 `cd` 命令解析，支持工作目录切换



开发环境

\- 语言: C++17

\- UI 框架: Qt 6.12.0 (MSVC 2022 64-bit)

\- IDE: Visual Studio 2022



如何编译运行

1\. 克隆本仓库到本地。

2\. 使用 Visual Studio 打开 `CMDGUI.sln`。

3\. 安装Qt,并配置Qt,安装插件Qt Visual Studio Tools

4\. 按 `F5` 编译运行。
